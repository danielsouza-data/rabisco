# Explicando com Rabisco — Site Público & Verificação de Domínio

Este repositório hospeda o site público do canal **Explicando com Rabisco** (@explicandocomrabisco), servido via GitHub Pages.

## Para que serve

- **Documentação legal:** Disponibiliza publicamente a **Política de Privacidade** e os **Termos de Uso** exigidos por plataformas externas (Google Cloud para integrações do YouTube e TikTok for Developers para leitura de métricas do canal).
- **Verificação de domínio:** Contém o arquivo de verificação exigido pelo TikTok for Developers.

## Estrutura dos Arquivos

| Arquivo | Função |
|---|---|
| `index.html` | Página inicial do site de suporte e conformidade |
| `privacidade.html` | Política de Privacidade do canal |
| `termos.html` | Termos de Uso aplicados |
| `estilo.css` | Folha de estilos do site |
| `tiktok*.txt` | Arquivo de verificação de propriedade de domínio para o TikTok |

## ⚠️ Avisos Críticos

- **Não apagar, renomear nem tornar privado** este repositório ou qualquer um de seus arquivos. A alteração ou remoção invalida a verificação dos aplicativos junto ao Google e ao TikTok, interrompendo as integrações oficiais. Qualquer alteração de endereço exige atualização cadastral nos painéis de desenvolvedor correspondentes.
- **Código privado:** O código-fonte, roteiros, ferramentas e ativos de produção do canal residem em um repositório privado independente.
- **Segurança:** Nenhum dado sensível, chave de API, segredo, token ou informação pessoal é mantido neste repositório público.
